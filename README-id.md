## Fitur 🎯

### Alur Kerja Pembuatan

- [x] Gunakan alur kerja **AI Agent, WebUI, API, atau CLI** untuk pembuatan cepat atau produksi otomatis
- [x] Dari topik menjadi naskah, narasi, footage, subtitle, musik, dan penyuntingan secara otomatis, sambil tetap memegang kendali di setiap tahap
- [x] Buat beberapa varian keluaran secara batch, tinjau riwayat tugas, serta impor atau ekspor pengaturan pembuatan dan kunci API
- [x] Pantau kemajuan mulai dari pembuatan naskah, narasi, unduhan footage, pemrosesan klip, hingga render akhir

### Naskah dan Penyedia Model

- [x] Gunakan langganan ChatGPT lewat [OpenAI - Codex](docs/codex-provider.md), dengan login kode perangkat dan pemilih model dinamis

## Pemasangan & Deployment 📥

### Pasang Paket Resmi dengan pip

Paket PyPI resmi adalah **[mpt](https://pypi.org/project/mpt/)**,
dikelola oleh `harry0703`. Paket `MoneyPrinterTurbo` di PyPI dikelola oleh pihak ketiga.

Tidak perlu meng-clone repositori. Memerlukan Python 3.11 atau lebih baru; Python 3.11 direkomendasikan.

**① Buat dan aktifkan virtual environment**

macOS / Linux:

```shell
python3 -m venv .venv
source .venv/bin/activate
```

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**② Pasang dan jalankan**

```shell
python -m pip install mpt
mpt webui
```

WebUI terbuka otomatis di browser Anda. Gunakan `mpt webui --port 8503 --headless`
untuk memilih port tanpa membuka browser. Untuk pembuatan video lewat CLI, lihat `mpt cli --help`.

**③ Konfigurasikan layanan dan temukan file Anda**

Aplikasi membuat `config.toml` pada peluncuran pertama. Tambahkan kunci API yang diperlukan
untuk model online, footage, atau layanan suara di pengaturan dasar WebUI.
Aplikasi yang terpasang menyimpan konfigurasi dan file hasil di lokasi berikut secara default:

| Sistem  | Direktori data                                                            |
| ------- | ------------------------------------------------------------------------- |
| macOS   | `~/Library/Application Support/MoneyPrinterTurbo`                         |

Atur `MPT_HOME` sebelum peluncuran untuk memilih direktori lain. Video hasil berada di
`storage/tasks` dalam direktori tersebut. Untuk memperbarui, aktifkan virtual environment Anda lalu
jalankan `python -m pip install --upgrade mpt`.

### Deployment Manual 📦

#### ① Buat Virtual Environment Python

Gunakan [uv](https://docs.astral.sh/uv/) untuk mengelola environment Python dan dependensi. Proyek ini mendukung Python 3.11 atau lebih baru; contoh di bawah memakai Python 3.11.

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

Jika Anda belum memakai `uv`, Anda tetap dapat memakai `venv + pip`.

```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Catatan:

- `pyproject.toml` kini menjadi manifes dependensi utama.
- `uv.lock` mengunci environment yang sudah di-resolve, sehingga `uv sync --frozen` direkomendasikan secara default.
- `requirements.txt` dipertahankan hanya untuk pemasangan `pip` lama.

#### ② Jalankan WebUI 🌐

Perhatikan bahwa Anda perlu menjalankan perintah berikut di `direktori root` proyek MoneyPrinterTurbo

###### Windows

```powershell
.\webui.bat
```

Anda juga dapat menjalankan `webui.bat` di CMD.
`webui.bat` memprioritaskan `.venv` proyek atau Python bawaan dari paket portabel. Jika Python proyek tidak ditemukan tetapi `uv` terpasang, otomatis beralih ke `uv run streamlit`.
Agar perangkat lain di LAN Anda dapat mengakses WebUI, jalankan `set MPT_WEBUI_HOST=0.0.0.0` sebelum menjalankan `webui.bat`.

###### macOS atau Linux

```shell
sh webui.sh
```

Skrip otomatis memakai virtual environment proyek atau `uv` dan memilih port lokal yang tersedia. Agar dapat diakses dari perangkat lain di LAN Anda, jalankan:

```shell
MPT_WEBUI_HOST=0.0.0.0 sh webui.sh
```

Setelah dijalankan, browser akan terbuka otomatis

#### ③ Jalankan Layanan API 🚀

```shell
uv run python main.py
```

Jika Anda sudah mengaktifkan virtual environment secara manual, Anda tetap dapat menjalankan:

```shell
python main.py
```

```shell
uv run python cli.py --video-subject "Bagaimana AI mengubah kehidupan sehari-hari"
```

Gaya subtitle dan opsi narasi di-resolve dengan urutan: **opsi CLI eksplisit >
nilai `[ui]` tersimpan di `config.toml` > default bawaan**. Pengaturan pembuatan lain,
seperti musik latar, jumlah video, dan jumlah paragraf, tidak diwarisi dari
WebUI. Jika WebUI diatur memakai audio yang diunggah, berikan `--custom-audio-file`
secara eksplisit, karena path unggahan tidak disimpan.

Untuk referensi perintah lengkap, deskripsi parameter, dan petunjuk penggunaan,
jalankan:

```shell
uv run python cli.py --help
```

Untuk menjalankan beberapa tugas secara berurutan, berikan array JSON UTF-8 atau manifes JSONL. Opsi CLI
berperan sebagai default, dan setiap objek menimpa field dari `VideoParams`:

```json
[
  { "video_subject": "How solar panels work" },
  { "video_subject": "How wind turbines work", "video_aspect": "16:9" }
]
```

```shell
uv run python cli.py --batch-file ./tasks.json --stop-at video
```

Manifes di-resolve dari direktori kerja saat ini. Nilai relatif
`custom_audio_file` dan `video_materials[].url` lokal di dalamnya di-resolve
dari direktori manifes; path file yang diberikan sebagai default CLI mempertahankan semantik
direktori kerja saat ini yang normal. Sebuah manifes dibatasi 100 tugas dan 1 MiB.
Semua entri divalidasi sebelum tugas pertama dimulai, tugas dilanjutkan setelah kegagalan runtime
individual, dan perintah mencetak satu ringkasan JSON setelah selesai.
Ringkasan berisi `total`, `succeeded`, `failed`, dan `tasks`; setiap entri tugas memiliki
`index`, `task_id`, `status`, `result`, `failed_stage`, dan `error`.

## Narasi, Subtitle, dan Musik Latar 🎙️

### Sintesis Suara

Kecepatan bicara ElevenLabs bergantung pada model yang dipilih. Default `eleven_multilingual_v2` menerima 0,7×–1,2×; pilih `eleven_v3` untuk rentang REST yang lebih lebar, 0,25×–4,0×. MoneyPrinterTurbo melaporkan pilihan yang tidak didukung sebelum mengirim permintaan pembuatan dan mempertahankan laju yang dipilih tanpa membatasinya. Kecepatan non-default pada `eleven_v4`/`eleven_v4_turbo` tidak didukung. ID model lain memakai rentang validasi konservatif 0,7×–1,2×; ini tidak menjamin setiap model mendukung pengaturan kecepatan. Jika penyedia mengembalikan `invalid_voice_settings`, pembuatan berhenti tanpa mencoba ulang dan menampilkan penjelasannya. [Validasi v2/v3 langsung yang dilaporkan pengelola](https://github.com/harry0703/MoneyPrinterTurbo/pull/1578#issuecomment-6040107858) lebih diutamakan daripada rentang yang lebih luas pada [referensi pengaturan suara resmi](https://github.com/elevenlabs/skills/blob/main/text-to-speech/references/voice-settings.md).

**VoiceStudio TTS** (default di WebUI) memakai server [VoiceStudio](http://localhost:3900) lokal lewat API kompatibel OpenAI (`POST /v1/audio/speech`); daftar suara dibaca dari `GET /v1/audio/voices`. Atur di `config.toml`:

```toml
[voicestudio]
base_url = "http://localhost:3900"
model = "tts-1"      # alias untuk engine aktif VoiceStudio
voices = []          # kosong = baca dari server
```

VoiceStudio tidak mengembalikan timestamp per kata, jadi gunakan `subtitle_provider = "whisper"` (ASR VoiceStudio) agar subtitle selaras dengan suara.

Satu-satunya penyedia suara adalah VoiceStudio; Edge TTS, Azure, SiliconFlow, Gemini, MiMo, MiniMax, ElevenLabs (suara), Chatterbox, Kokoro, Fish Audio, dan VoxCPM telah dihapus. Mode tanpa suara dan unggah audio sendiri tetap tersedia. ElevenLabs hanya dipakai untuk musik latar (Video-to-Music).

Pilih suara di WebUI. VoiceStudio tidak memerlukan kunci API; penyedia cloud lain memerlukan kredensial dari platform masing-masing.


### Pembuatan Subtitle

Tersedia dua mode pembuatan subtitle:

- **edge**: Memakai timestamp kata dari hasil TTS (hanya untuk penyedia yang mengembalikannya).
- **whisper** (default): Mengirim audio ke server [VoiceStudio](http://localhost:3900) lokal lewat API kompatibel OpenAI (`POST /v1/audio/transcriptions`) bila timeline subtitle yang lebih akurat diperlukan. Tidak ada pustaka atau model Whisper yang dipasang oleh aplikasi ini; pastikan VoiceStudio berjalan.

Atur `subtitle_provider` di `config.toml` untuk berganti mode, dan arahkan ke server VoiceStudio Anda:

```toml
[app]
subtitle_provider = "whisper"

[whisper]
base_url = "http://localhost:3900"
model = "whisper-1"
# language = "id"   # opsional, kosong = deteksi otomatis
timeout = 600
```

## Pertanyaan Umum 🤔

<details>
<summary>RuntimeError: No ffmpeg exe could be found</summary>

Biasanya ffmpeg akan diunduh dan dideteksi secara otomatis.
Namun, jika environment Anda bermasalah sehingga unduhan otomatis tidak dapat berjalan, Anda mungkin menemui error berikut:

```
RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.
```

Dalam kasus ini, unduh FFmpeg dari [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), ekstrak, lalu atur `ffmpeg_path` ke
path pemasangan yang sebenarnya.

```toml
[app]
# Sesuaikan dengan path Anda yang sebenarnya, perhatikan bahwa pemisah path Windows adalah \\
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

</details>

<details>
<summary>OSError: [Errno 24] Too many open files</summary>

Masalah ini disebabkan oleh batas jumlah file terbuka pada sistem. Anda dapat mengatasinya dengan mengubah batas file terbuka sistem.

Periksa batas saat ini:

```shell
ulimit -n
```

Jika terlalu rendah, Anda dapat menaikkannya, misalnya:

```shell
ulimit -n 10240
```

</details>

<details>
<summary>Transkripsi subtitle gagal (VoiceStudio)</summary>

```
VoiceStudio transcription failed: ConnectionError ...
```

Pastikan VoiceStudio berjalan dan `base_url` di bagian `[whisper]` pada `config.toml` benar. Periksa dengan `curl http://localhost:3900/health`.

</details>
